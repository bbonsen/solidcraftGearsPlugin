Gears builds gears in SolidCraft as ordinary, editable sketches, extrudes and sweeps. The first public release.

## Install

1. Download **gears-0.10.0.zip** below.
2. In SolidCraft (desktop): **Preferences › Plugins › Install plugin…** and pick the zip. It asks for no permissions.
3. The commands appear in the **Plugins** group on the **Model** tab and in the Plugins menu.

**Requires SolidCraft 0.43.0 or later.** In 0.42.0, running a command crashes the app.

## Commands

| Command | Builds |
|---|---|
| Spur gear | Involute spur gear, extruded; optionally crowned (lofted) |
| Helical gear | Twisted sweep of the transverse profile |
| Herringbone gear | Two helical halves of opposite hand, joined |
| Internal gear | Ring with inward teeth |
| Planetary gear set | Sun, planets and ring, each a body, placed in mesh |
| Rack and pinion | Exact rack, plus an optional spur pinion in mesh |
| Bevel gear | Straight bevel (Tredgold heel profile, swept to the apex) |
| Hypoid gear | Spiral-bevel approximation sized by first-order hypoid rules |
| Worm | Exact thread section swept one turn per lead |
| Worm wheel | Helical wheel matched to a worm (not throated) |
| Cycloidal gear | Clock-style cycloidal teeth, optionally with its mate in mesh |
| Cycloidal drive | Lobed disc and pin housing |

Tooth options: profile shift, root fillet and tip relief (spur, helical, herringbone, rack pinion; fillet and relief on planetary sets) and crowning (spur). A warning gives the profile shift that avoids undercut.

## Notes

- The plugin runs sandboxed: no file, network or settings access. Each run is one undo step.
- SolidCraft's plugin API (`craft:plugin@0.1.0`) is experimental, and so is this plugin. Spur has been run in SolidCraft 0.43.0; every command has been run in SolidCraft's plugin runtime, but the others have not all been tried in the app yet. Crowned spurs, long worms, herringbone and hypoid gears are the heaviest for SolidCraft's kernel. Please report anything that fails.
- Hypoid gears are an approximation, not machine-generated hypoid flanks; see the README.
